# P6.6 / 0.8.6 科学规划、知识与工作流

P6.6 的原则是“模型选择时机，用户和目录冻结内容”。TaskSpec 可选保存 `agent_workflow`、`agent_analysis` 和 `agent_claim`。模型不能把任意输入、参数、命令或规则传给写工具；受控适配器重新读取当前 TaskSpec，经既有 P4 Workflow 与 P5 Research 契约验证后才写入。

新增四个受控工具：提交冻结工作流、创建探索分析修订、登记分析、创建拟议主张。主张默认为任务冻结模板中的状态；Agent 不能把拟议或未核验内容改成验收事实。工作流仍检查包摘要、精确输入、授权、预算、节点许可和发布。

Knowledge 搜索继续只做发现，精确读取才形成 EvidenceRef 和读取回执。研究修订重新验证证据生命周期；撤回资料不能支持新修订。`groundwater-head-comparison-v1` 仍由 P5 的确定性策略执行，未做水头比较时不会阻止普通统计、格式检查或制图。
