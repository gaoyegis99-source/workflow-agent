# P1 执行组件选型

状态：ACCEPTED

## 决定

V7 的受控 CWL 执行使用锁定的 Toil/cwltool 运行时。Weaver 只保留为对照实验，不接入平台；
gVisor 只作为隔离探针，不自动等同于生产执行沙箱。

选择规则是失败关闭的：隔离门禁必须先通过；执行引擎必须同时满足稳定任务身份、重复提交不新增
执行、跨进程重定位、恢复和实际计算取消。缺失、重复或 `NOT_RUN` 的检查不能凑成通过，也不能用
加权分数抵消失败。

## 必须保留的约束

1. 步骤身份不能只依赖引擎显示名；必须结合冻结路径、scatter 序号、节点身份和引擎 job ID。
2. 定位失败不等于任务不存在；身份存在但状态未知时保持 `UNKNOWN`，阻止自动重复提交。
3. 取消必须验证实际计算停止；只观察 API 终态不足以允许发布。
4. 隔离能力只适用于经过验收的精确配置，不能外推为任意无特权部署或逃逸安全证明。
5. 实验、平台集成和部署验收相互独立；任何一层通过都不能替代另外两层。
