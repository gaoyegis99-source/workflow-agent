## 发现的问题

1. **高优先级，已修复：客户端缺失。** 仓库原先没有 `PLATFORM_EMBEDDING_BASE_URL` 客户端，README 仍写着 Embedding 未实现。现已补充端口、适配器、限制、错误分类和仓库外安装验证。
2. **中优先级，开放限制：延迟波动。** 4B 质量完全稳定，但三轮总墙钟相差超过一个数量级。网关的 `elapsed_ms` 不覆盖客户端观察到的全部等待，Embedding 暂时不能成为 Agent 强制关键路径。
3. **中优先级，已缓解：策略语义混淆。** 0.6B 与 BGE 均把 A08 排到第二名。检索只返回候选，地下水量纲、垂向基准、权限和工具准入继续由确定性规则判断。
4. **中优先级，开放限制：模型制品不可复核。** 返回只有模型别名和 Worker，没有不可变权重或量化文件摘要；相同目录不能证明未来仍是相同模型制品。
5. **低优先级，开放限制：服务无应用凭据。** 当前局域网端点不要求应用级认证，需要依赖网络隔离；接入生产 Knowledge 前应增加服务身份或网关认证。
6. **信息项：模拟模型的能力边界。** 确定性 LLM 能证明编排、身份、恢复和防伪，不证明自然语言推理质量；此前真实模型 45/45 证据仍独立保留。

## 阶段结论

P6.10 诊断通过。推荐模型保持 `qwen3-embedding-4b-q4`、1024 维，但仅作为非权威候选检索能力。未把 Embedding 接入生产 Knowledge 搜索，也未改变 P6 完成、工具授权或 P5 验收语义。
