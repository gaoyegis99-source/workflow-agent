# P4.2.1 空间资产与 QGIS 闭环验收报告

> **HISTORICAL.** 本报告是该阶段的冻结实现或验收记录，不代表当前活动 Release 或当前实现状态。当前发行身份见 [当前发布指针](p82-current-release.json)。

当前版本：八个 V7 Python 发行包及 CWL runtime `0.4.0`。基线为 P4.1 R5 `0.3.8`。

## 完成内容

- GeoPackage 与 GeoTIFF 通过独立空间 Worker 和固定检查容器导入，保存精确 driver、摘要、CRS、轴顺序、范围、图层/字段或波段/NoData。Data 服务本身不导入 QGIS SDK。
- `spatial-generic-v1` 支持资产、图层、字段和波段的命名空间注解，同时保护检查器提取事实不被语义声明覆盖。
- 实现受信 `qgis-buffer@1.0.0` 与独立 Native `spatial-vector-summary@1.0.0`。Buffer 拒绝地理坐标输入和非米制输出 CRS；英尺投影输入通过显式重投影后可运行。
- Execution 使用封闭实现注册表、端口化 File 绑定、固定镜像/资源/输出契约。派生 File 必须来自唯一成功节点且摘要匹配。
- 冻结 `qgis-buffer-summary-v1` 工作流，两个实际节点各消耗一次额度，中间成果私有，最终命名输出集合原子发布。空间任务没有自动验收模板，成功后保持 `OPEN`。
- 最小任务页支持空间上传、元数据、语义、任务/授权、Buffer 参数、节点状态、取消及成果下载；不含地图预览、编辑器、脚本或插件。

## 测试与修复

统一入口 `bash scripts/check_p4.sh --phase spatial` 及补齐迁移用例后的完整回归均以 0 退出：最终 494 项 pytest 和 13 项 P1 规则全部通过，0 失败、0 错误、0 跳过。八个 wheel 与八个 sdist 在仓库外锁定安装；安装后的 API、CLI、三个数据库迁移、P3 容器、P4.1 Toil、GeoPackage 检查、QGIS Buffer、Native 摘要和原子发布全部通过。最终环境和不可变镜像记录在[结构化证据](p42-spatial-evidence.json)。

开发回归发现并修复：QGIS 在只读输入上创建临时表失败、QGIS 退出后 GDAL driver 注销导致输出复查失败、CWL 嵌套 record 默认值不兼容、扩展算子目录破坏旧基准的“两项”假设、依赖边界未表达固定空间运行时例外，以及浏览器在父额度全部预留后错误等待按钮重新启用。修复均有回归用例。

空间夹具覆盖米制和英尺投影、EPSG:4326、空/多/冲突图层、缺失 CRS、无效或空几何、损坏 GeoPackage，以及单/多波段、NoData、缺失 CRS和损坏 GeoTIFF。夹具与期望摘要冻结在仓库，不需要在线数据。

## 范围与限制

- GeoTIFF 本轮只有导入、检查、查询和下载，没有栅格算子。
- 不实现表格转点、复杂制图、样式、插件、用户代码、远程执行或空间任务自动科学验收。
- 恢复能力限于同一主机、同一 Docker daemon 和持久工作目录；没有声明跨主机 HA 或生产 SLA。
- 语义注解表示用户/领域声明，不能单独证明声明与现实观测一致。

**P4.2.1 通过。** 结构化证据状态为 `PASS`。本轮到此结束，不进入制图扩展、P4.3 或 P5。
