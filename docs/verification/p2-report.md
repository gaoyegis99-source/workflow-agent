# P2 控制核心阶段报告（首次验收历史记录）

> **HISTORICAL.** 本报告是该阶段的冻结实现或验收记录，不代表当前活动 Release 或当前实现状态。当前发行身份见 [当前发布指针](p82-current-release.json)。

> 本文件记录 0.1.0／0001_control 的首次验收结果。后续审计复现了成员变更死锁、重复观察不能恢复、非法执行标识导致查询 500 三个缺陷，首次覆盖不足以证明这些场景通过。当前验收结论以 [P2 补齐与重新验收报告](p2-followup-report.md) 为准；下文结论仅为当时记录。

验收日期：2026-10-12（Asia/Shanghai）。统一入口于 2026-10-11 20:37 UTC 完成。**结论：P2 通过，本轮结束；不进入 P3。**

## 完成内容

- 独立 PostgreSQL 17 数据库、SQLAlchemy 仓储与 UnitOfWork、Alembic 初始迁移 `0001_control`；显式迁移，启动只检查版本。完整依赖锁和数据库镜像 digest 已固定。
- 本机操作者／令牌 CLI：高熵 Bearer Token 仅签发时显示，数据库只存摘要；支持过期、撤销。项目 OWNER／EDITOR／VIEWER 隔离，成员 CLI 重新验证当前 OWNER，保护最后一名 OWNER。
- 持久项目与 DIRECT 任务，分页查询、不可变要求修订、独立控制版本、暂停／恢复／取消与清理状态。AGENT 明确拒绝，未提供任意状态修改或手工完成接口。
- 任务范围授权绑定精确资源与计算目标，记录有效期、授权代次、撤销者和撤销时间。每次访问及幂等重放复核当前权限，包括全局创建项目请求的重放。
- 执行次数与在途上限、按 Action 唯一预留、结算记录；Action 冻结请求、CLIENT 决定来源与历史关联。准入与预算、命令、幂等、发送 outbox 原子提交。
- 独立 Worker，队列领取／续租／代次隔离、发送前复核、inbox 去重和版本防回退、未知状态保留、指数退避恢复。Command 是查询投影，不是另一套计算调度器。
- 独立测试 HTTP 服务提供持久幂等提交、查询、取消封存、断响应及延迟注入。生产包和 Worker 不加载这个服务，也没有 `/executions` 路由。

实际 API：项目创建／发现／查询；任务创建／分页／查询／要求修订／暂停／恢复／取消；任务范围授权列表／创建／撤销；预算查询；命令查询；健康、就绪及 OpenAPI。字段、状态码、幂等和取消语义见 [P2 接口契约](../contracts/p2-control-contracts.md)。

## 问题处理

已修复并回归验证：

1. PostgreSQL 初始化期间临时 Unix socket 已就绪而 TCP 服务尚未就绪：测试改为检查 TCP，避免过早连接。
2. psycopg 对某些 INSERT 的 rowcount 不可靠：inbox 使用 `RETURNING` 判定是否首次写入，确保首次观察能够正确结算。
3. P0 路径正则在 FastAPI 默认正则引擎中不兼容：使用已编译 Python 正则，保留严格标识符约束。
4. 已有投递尝试数不等于连续故障数：增加独立失败计数，成功观察后重置，退避从 1 秒重新开始。
5. 全局创建项目的重放不能只验证身份：补充原项目当前成员校验，并添加 HTTP 回归。
6. 领取租约时读取的时间不能用于等待行锁后的授权：取得行锁后重新读取数据库时间，续租和释放条件使用数据库时钟。
7. 补齐成员 CLI 的 OWNER 校验、授权撤销审计、预算结算记录；统一身份／任务／投递锁顺序，降低成员变更与命令竞争导致的死锁风险。
8. 旧的“三个发行包、只有健康路由”断言已更新；测试覆盖全部实际包和接口，不再将新增能力误判为越界。

当前没有阻断 P2 验收的已知缺口。修复后运行了针对性检查和最后一轮完整统一入口；没有把未通过场景排除或改为跳过。

## 范围、未执行项与局限

- **严格停止在 P2。** Task 控制可由真实 API 使用；计算 Action 由内部应用入口和测试适配器验证，正式 `/executions` 接口留到 P3。没有 Data、科学算子、发布、独立科学验收、Knowledge、Agent 或任务页面。
- 未重跑 P1 重型 Toil／Weaver／gVisor 实验，因为组件适配源码未修改；与 P1 证据中的组件输入摘要核对一致，13 项规则回归通过。原 Toil 选型不变。
- 真实 HTTP 端口超时为 5 秒，生产 Worker 默认 30 秒租约／10 秒续租。接管故障测试通过数据库推进租约时间，验证真实进程接管和 fencing；心跳测试缩短租约以测试跨期续租，不是生产计时精度基准。
- 独立模拟服务的 SQLite 只保存模拟外部事实；平台从未以 SQLite 代替 PostgreSQL。外部恰好执行一次依赖适配器的稳定 Action 身份和持久幂等／封存能力，不等于对任意外部计算服务提供无条件保证。
- 同任务控制和预算按任务行串行；目前每个 Worker 逐个处理外呼、正常活动每秒轮询。并发正确性已测，生产吞吐、长期容量、性能调优及数据库备份升级回退尚未验收，属于 P8。
- Grant 仅验证引用范围，不证明资源存在或 manifest 正确；要求文本不构成科学验收协议；命令 RESOLVED 和 Task CANCELLED 均不能当作科学计算成功或已停止的证明。
- 初始迁移从空的 V7 数据库验收，没有迁移或复用 V6 数据。V6 HEAD 只读核对仍为 `839c4f5aa8edb69bcd180bf24b45ead7dd20421b`；本轮未修改其代码、部署或运行资源。

验收后已核对：本轮标签下的 PostgreSQL 测试容器、网络、卷，以及模拟服务／Worker 子进程均已清理，没有留下测试服务充当生产部署。
